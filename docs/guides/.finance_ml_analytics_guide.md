# Finance ML Analytics Guide

This guide provides relevant details for future development on the `finance_ml/analytics` package.

## 1. Build/Configuration Instructions

### Module Organization
The `finance_ml/analytics/` package is structured as follows:

- `finance_ml/analytics/`
    - `__init__.py`: Package exports (128 lines)
    - `data_utils.py`: Data loading and preprocessing (2046 lines)
    - `statistical_analysis.py`: Advanced statistical methods (1282 lines)
    - `screening.py`: Stock screening functions (691 lines)
    - `feature_analytics.py`: Visualization dashboards (1644 lines)
    - `probability_analytics.py`: Probability models (1827 lines)
    - `optimized_ops.py`: Performance optimizations (622 lines)
    - `visualizations/`:
        - `__init__.py`: Visualization package exports (257 lines)
        - `profitability.py`: Margin and profitability charts (647 lines)
        - `technical.py`: Technical analysis charts (565 lines)
        - `temporal_analysis.py`: Time series analysis (769 lines)
        - `category_charts.py`: Category-specific charts
        - `valuation.py`: Valuation analysis charts (669 lines) [NEW v2.1]
        - `earnings_quality.py`: Earnings quality charts (658 lines) [NEW v2.1]
        - `quality_risk.py`: Quality & risk charts (852 lines) [NEW v2.1]
        - `growth_analysis.py`: Growth metrics charts (631 lines) [NEW v2.1]
        - `probability_viz.py`: Probabilistic ArviZ-backed charts (857 lines) [NEW v2.4]

### Main Script
- `market_analytics.py`: Main demonstration script (approx. 1000 lines), showcases the integration of all modules.

## 2. Testing Information

### Configuring and Running Tests
The project uses `pytest` for testing. You can run all analytics-related tests from the project root:

```bash
pytest tests/test_screening.py tests/test_data_utils.py tests/test_statistical_analysis.py tests/test_market_analytics_integration.py tests/test_visualizations.py tests/test_enhanced_statistics.py -v
```

### Test Coverage Summary
The refactored modules have comprehensive test coverage (Total: 212+ tests):

| Test File                              | Tests         | Coverage                       |
|----------------------------------------|---------------|--------------------------------|
| `test_screening.py`                    | 42 tests      | Screening functions            |
| `test_data_utils.py`                   | 38 tests      | Data loading and preprocessing |
| `test_statistical_analysis.py`         | 39 tests      | Bayesian, MCMC, distributions  |
| `test_market_analytics_integration.py` | 18 tests      | Cross-module workflows         |
| `test_visualizations.py`               | 35 tests      | All 12 visualization functions |
| `test_enhanced_statistics.py`          | 40 tests      | Kalman, Copula, parallel MCMC  |

### Guidelines for Adding New Tests
1. **Location**: Place new tests in the `tests/` directory.
2. **Naming**: Test files should be named `test_*.py`.
3. **Methods**: Use `unittest.TestCase` or `pytest` style functions.
4. **Integration**: Add new tests to `test_market_analytics_integration.py` if testing cross-module workflows.

### Demonstration Test
A simple demonstration test `tests/test_analytics_demo.py` was created to verify the utility functions:

```python
import unittest
import pandas as pd
from finance_ml.analytics.data_utils import compute_metric_statistics

class TestAnalyticsDemo(unittest.TestCase):
    def test_compute_metric_statistics(self):
        data = pd.Series([10, 20, 30, 40, 50])
        stats = compute_metric_statistics(data)
        self.assertEqual(stats['mean'], 30.0)
```

## 3. Additional Development Information

### Core Refactored Modules
- `finance_ml/analytics/data_utils.py`: Data loading and preprocessing.
- `finance_ml/analytics/statistical_analysis.py`: Bayesian, MCMC, Kalman, Copula.
- `finance_ml/analytics/screening.py`: Stock screening functions.
- `finance_ml/analytics/feature_analytics.py`: Interactive visualizations.
- `finance_ml/analytics/optimized_ops.py`: Performance optimizations.

### Visualization Modules (v2.0 - v2.4)
- `profitability.py`: Margin analysis.
- `technical.py`: Technical analysis.
- `temporal_analysis.py`: Time series analysis.
- `valuation.py`: Valuation ratio analysis (v2.1).
- `earnings_quality.py`: Earnings quality charts (v2.1).
- `quality_risk.py`: Quality & risk assessment (v2.1).
- `growth_analysis.py`: Growth metrics analysis (v2.1).
- `probability_viz.py`: Probabilistic ArviZ-backed charts (v2.4).

### Contributing

#### Adding New Screening Functions
1. Add function to `screening.py`.
2. Follow existing naming conventions and include comprehensive docstrings.
3. Write unit tests in `test_screening.py`.

#### Adding New Statistical Methods
1. Add function to `statistical_analysis.py`.
2. Include mathematical documentation and references.
3. Add validation tests in `test_statistical_analysis.py` or `test_enhanced_statistics.py`.
