# Finance ML Analytics Dashboards

This directory contains interactive dashboard applications for the Finance ML Analytics Platform.

## 🚀 Quick Start

### Streamlit Dashboard (Recommended)

Comprehensive analytics platform with multi-page navigation, advanced reporting, and governance features.

```bash
streamlit run finance_ml/dashboards/streamlit_app.py
```

**Features:**

- 📋 Executive Summary
- 📈 Financial Analytics Overview
- 🎯 Stock Ranking & Sector Analysis
- 🔬 Uncertainty & Calibration (Phase 9.4 & 9.7)
- 🛡️ Safety Rails & Data Quality (Phase 9.5)
- 🏛️ Model Governance & Lineage (Phase 9.8)
- 💼 Portfolio Optimization (Phase 10)

### Dash Dashboard

High-performance dashboard focused on real-time interactivity and core metrics.

```bash
python finance_ml/dashboards/dash_app.py
```

## 🔧 Setup

Ensure you have run the necessary pipeline steps to generate artifacts:

1. **Run the main pipeline:**
   ```bash
   python ml_finance_model_main.py --data-source auto --limit 5000
   ```

2. **Sync dashboard assets (HTML reports):**
   ```bash
   python tools/setup_dashboard_assets.py
   ```
   This copies generated HTML reports from `outputs/` to the dashboard's asset directory.

## 📊 Available Artifacts

The dashboards automatically detect and display artifacts generated by the pipeline:

- **Uncertainty**: Interval widths, coverage heatmaps, reliability diagrams
- **Calibration**: Sector bias dashboards
- **Safety Rails**: Winsorization effects, constraint violations
- **EDA**: Feature correlations, sector bubbles, regional radar charts
- **Governance**: Model cards, error maps
- **Portfolio**: Efficient frontier, risk decomposition, backtesting results
